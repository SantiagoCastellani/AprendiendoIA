# Proyecto de Aprendizaje de Inteligencia Artificial 🧠🤖

Bienvenido a este repositorio de prácticas y ejercicios de Inteligencia Artificial realizados con Python y Google Colab.

El objetivo de este proyecto es aprender progresivamente conceptos fundamentales de IA, Machine Learning y Deep Learning mediante ejemplos prácticos y experimentación.

---

# 🚀 Tecnologías utilizadas

- Python
- TensorFlow
- Keras
- Google Colab
- Numpy
- Matplotlib

---

# 📚 Contenido del repositorio

Este repositorio irá incorporando ejercicios y proyectos relacionados con:

- Redes neuronales
- Clasificación de imágenes
- Deep Learning
- Computer Vision
- Predicción y entrenamiento de modelos
- Procesamiento de datos
- Experimentación con datasets
